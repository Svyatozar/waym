# AGENTS.md

Инструкции для ИИ-агентов в этом репозитории.

## Что это за проект

Репозиторий контент-стратегии блога Святозара (сценарии, стратегия, воронка). Это **не** веб-сайт и не приложение — не предлагай Next.js, лендинги и деплой сайта, пока явно не попросят.

## Перед любой задачей по контенту

1. Прочитай `content/author-profile.md`
2. При стратегии/воронке — ещё `content/strategy/overview.md`
3. Следуй правилам в `.cursor/rules/content-strategy.mdc`

## Стиль ответов и материалов

- Кратко и конкретно
- Без воды и экспертной позы
- На реальных историях автора
- Идея: маленькие действия несмотря на страх

## Структура

| Путь | Назначение |
| --- | --- |
| `content/author-profile.md` | профиль автора |
| `content/strategy/` | стратегия и воронка |
| `content/scripts/reels/` | сценарии коротких видео |
| `content/scripts/youtube/` | сценарии длинных видео |
| `content/ideas/` | идеи и гипотезы |
