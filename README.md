# Контент-стратегия блога Святозара

Репозиторий для разработки контент-стратегии, сценариев и воронки блога. Сайта здесь нет — только рабочие документы для контента.

## Структура

```
content/
  author-profile.md   # профиль автора (базовый контекст)
  strategy/           # стратегия, позиционирование, воронка
  scripts/
    reels/            # сценарии коротких видео
    youtube/          # сценарии длинных роликов
  ideas/              # банк идей и гипотез
```

## С чего начинать агентам

1. Прочитать [content/author-profile.md](content/author-profile.md)
2. Следовать правилам в [.cursor/rules/](.cursor/rules/) и [AGENTS.md](AGENTS.md)
3. Писать конкретно, на реальных историях автора, без позы эксперта

## Принцип контента

Изменения — через маленькие регулярные действия несмотря на страх, а не через мотивацию и «измени мышление».
